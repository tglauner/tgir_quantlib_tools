\section{Deployment Test Inventory}
This catalog records the automated tests and smoke checks used before and after deployment. It is derived from the repository workflows, deployment notes, and unittest files.

\section{Individual unittest coverage}
\subsection{Cliquet identities}
\path{CliquetIdentityTests.test_cliquet_identity_portfolio} runs ten subcases showing that QuantLib cliquet pricing reduces to vanilla, forward-start strip, repeated-quarter, and deterministic zero-volatility limits.

\subsection{SOFR curve and Bermudan tests}
\texttt{SofrCurveTests} reprices quoted OIS swaps, checks zero-rate and daily-forward rows, validates the workbook ATM-vol surface, verifies swap point sensitivities, tests European swaption vega isolation, and confirms Bermudan calibration strips, fixed-final-maturity schedules, workbook-mark tracking, and G2++ parameters.

\subsection{Application smoke tests}
\texttt{PortfolioSmokeTests} verifies default portfolio pricing; login, dashboard, market-update, realtime-tick, and trade-editor flows; rates and cliquet analytics; risk APIs; template fallbacks; public health; the QuantLib data-model page; IBKR comparison; and curve-debug CSV download.

\section{Coverage summary}
Together these checks cover SOFR curve calibration, Bermudan model calibration and schedules, cliquet identities, portfolio pricing, Flask authentication and protected routes, trade editors, realtime and risk APIs, debug CSV export, Python compilation, documentation builds, and production health endpoints.
