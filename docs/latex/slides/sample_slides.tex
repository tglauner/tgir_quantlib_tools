\begin{frame}{Discounting Is the Core Transformation}
  A deterministic cash flow $C_i$ paid at time $t_i$ has present value
  \[
    PV = \sum_{i=1}^{n} C_i P(0,t_i).
  \]
  \begin{itemize}
    \item $P(0,t_i)$ comes from the calibrated discount curve.
    \item Every input has an as-of time and an explicit unit.
    \item Validation reprices the instruments used to build the curve.
  \end{itemize}
\end{frame}
